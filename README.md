# Language Skills for Engineers (LSFE)

Welcome to the official academic repository for the **Language Skills for Engineers (LSFE)** course at **KLH**. This repository serves as a digital portfolio containing all required coursework, laboratory exercises, and English language submissions completed throughout the semester.

## 📌 Course Information
* **Course Title:** Language Skills for Engineers (LSFE)
* **Institution:** KL University (KLH)
* **Objective:** Developing professional communication, technical writing, and linguistic proficiency for engineering workflows.

## 📁 Repository Structure
The repository is organized into the following sections:
* `Laboratory/` – Weekly English lab experiments, phonetics exercises, and interactive tasks.
* `Assignments/` – Formal written submissions, essays, and comprehension tasks.
* `Presentations/` – Slides and scripts for seminars and group discussions.

## 📑 Topics Covered
* Technical Report Writing & Documentation
* Professional Correspondence (Emails, Letters, Memos)
* Verbal Communication & Presentation Skills
* Grammar, Vocabulary, and Phonetics
